# Assets de marca del cliente

Coloca aquí la imagen de marca adjunta con el nombre:

```text
nebula-mark.png
```

Se utiliza en:

- Favicon global.
- Favicon y Apple Touch Icon del cliente web.
- Icono visual del header de `/cliente/app`.
- Icono configurado en la metadata de la app.

Idealmente debe ser un PNG cuadrado con fondo transparente, preferentemente de 512x512 px o mayor.
